## Algorithms chosen
1. **Linear search** - brute force, iterative, no preprocessing (`src/algo1_linear_search.py`)
2. **Binary search** - decrease-and-conquer, recursive, needs the records sorted once (`src/algo2_binary_search.py`)
3. **Hash table with separate chaining** - space-time trade-off (third strategy) (`src/algo3_hash_table.py`)

## How to run (reproduce everything)
```bash
pip install matplotlib
cd src
python dataset_generator.py --n 1000 --out ../data/sample_1000.csv   # sample dataset
python test_correctness.py                  # Task 8  - correctness for 1K, 10K, 100K, 1M
python benchmark.py --n 1000                # Task 9  - repeat with 10000, 100000, 1000000
python benchmark.py --all                   # ... or all four sizes in one go
python task12_benchmark.py                  # Task 12 - 50,000 searches on 1,000,000 records
python make_graphs.py                       # graphs from results/*.csv -> results/graphs/
```
Every program prints `Reg No | Name | Seed | date-time` first. Datasets are generated from seed 5147 (+ n), so
they are identical on every run; the dataset always contains reg no 192425147 (found) and never contains 192425148 (not found).
Timings depend on the machine; comparison counts do not.

Expected run time on an ordinary laptop: correctness test about 10 s, `benchmark.py --all` about 1 minute, `task12_benchmark.py` about 1 minute.
